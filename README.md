# Фигурная маска

Веб-инструмент: фото + фигура-маска + цвет → стильный кадр в двух вариантах.

## Что умеет
1. **Загрузка фото** — кнопка, drag&drop или вставка из буфера.
2. **Фигура-маска** — пресеты (круг, бинокль, овал, скруглённый прямоугольник, прямоугольник, арка, сердце, звезда, треугольник, шестиугольник) **или свой SVG** как маска.
3. **Цвет** — палитра + свой цвет.
4. **Два режима:**
   - **фото в фигуре** — фон залит цветом, внутри фигуры видно фото;
   - **цвет в фигуре** — фон это фото, фигура залита цветом.
5. **Настройки:** размер, положение (слайдеры или перетаскивание фигуры мышью), поворот, скругление, мягкость края, **блюр фото**.
6. **Экспорт:** PNG / JPG / WebP, качество, размеры (оригинал / 1080×1350 / 1080×1080 / 1080×1920 / 1920×1080), скачать текущий вариант или **оба сразу**.

Один статичный `index.html`, без зависимостей. Хостится на GitHub Pages.
